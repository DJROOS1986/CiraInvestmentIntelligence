# Authorization Boundary

## Authorized now
- Read and review this package.
- Discuss test scenarios and acceptance criteria.

## Not authorized now
- Creating or modifying files on the user's Windows computer.
- Executing the isolated E2E tests or mock processes.
- Replacing either Phase 5.8 runner.
- Running real monitoring collection or writing real history/logs.
- Registering or enabling Windows Scheduled Tasks.
- Azure operations, Git commits, production promotion, or recovery.

## Future approval (must be explicit)
Approval to *prepare* executable tests is distinct from approval to *execute* them. Approval to execute tests is distinct from approval to promote the runner. Each stage should be requested separately.
